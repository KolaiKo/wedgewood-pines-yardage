# Wedgewood Pines Yardage Book

A phone-first digital yardage book for Wedgewood Pines Country Club (Stow, MA): hole maps, tap-to-measure distances,
green slopes and contours, movable tees, shot tracking, and live GPS distances.

Open it on an iPhone in Safari, tap Share, then **Add to Home Screen** to use it like an app.
Rounds and shots are stored in the browser on that device.

Data: scorecard from the club's published card; course geometry © OpenStreetMap contributors (ODbL);
green elevations from USGS 3DEP lidar (public domain). Distances are approximate. Not affiliated with the club.
